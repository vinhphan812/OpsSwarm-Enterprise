# OpsSwarm Enterprise Branding

## Project icon

![OpsSwarm Enterprise icon](assets/opsswarm-enterprise-icon.svg)

The project icon represents the core OpsSwarm architecture:

- **Eight outer nodes** represent the governed S1–S8 Skill set and the coordinated swarm of specialist capabilities.
- **The shield boundary** represents policy enforcement, bounded execution, and human-governed authority.
- **The central pulse** represents observable incident telemetry and evidence-driven diagnosis.
- **The amber incident point** represents the active operational incident under investigation.
- **The green check** represents independent recovery verification before an incident is considered resolved.

The icon is intentionally vendor-neutral. It represents OpsSwarm itself rather than OpenClaw, GitHub, or any specific enterprise tool, so the visual identity remains reusable as the project evolves.

## Primary asset

- `docs/assets/opsswarm-enterprise-icon.svg` — canonical scalable vector icon.

The SVG uses a transparent canvas and is suitable for GitHub documentation, project pages, presentations, and derived raster exports.
