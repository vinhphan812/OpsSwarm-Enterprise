## 6. Release Gate Order

The release gates must pass in this exact order:

### Gate 1: Contracts & Reliability

- [ ] ADR-009-* implemented (idempotency)
- [ ] ADR-006 (skill contracts) validated
- [ ] Persistence layer passes idempotency tests

### Gate 2: Tests

- [ ] All 13 tests pass (pytest)
- [ ] Coverage > 73% baseline (80% target)
- [ ] Test markers defined (unit, integration)

### Gate 3: CI

- [ ] GitHub Actions workflow present
- [ ] ruff linting passes (0 errors)
- [ ] pytest runs on every push/PR

### Gate 4: Security

- [ ] bandit scan passes
- [ ] pip-audit finds no vulnerabilities
- [ ] SBOM generated (CycloneDX JSON)

### Gate 5: Release

- [ ] requirements.txt locked
- [ ] CHANGELOG.md updated
- [ ] Version tag created (v2.2.0)
