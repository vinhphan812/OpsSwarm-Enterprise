## Version consistency audit (G9)

Verify on the tagged commit before pushing the tag:

```bash
# 1. Tag matches pyproject.toml
git checkout refs/tags/v2.2.0
python -c "import tomllib; print(tomllib.load(open('pyproject.toml'))['project']['version'])"
# Expected: 2.2.0

# 2. opsswarm.__version__ matches pyproject.toml
python -c "import opsswarm; print(opsswarm.__version__)"
# Expected: 2.2.0

# 3. /health endpoint version matches
python -m uvicorn opsswarm.api:app &
sleep 2
curl http://localhost:8000/health | python -m json.tool
# Expected: "version": "2.2.0"

# 4. FastAPI app metadata version matches
python -c "from opsswarm.api import app; print(app.version)"
# Expected: 2.2.0
```
