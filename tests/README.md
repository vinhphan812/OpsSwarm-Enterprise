# Tests

Minimum test suites:
- `apps/api/tests` — health, store, inventory, and event intake, including invalid SKU and event responses
- `apps/web` — API client and store-status smoke tests, including an API failure that stays on screen
- tool contract tests
- Digital Twin state tests
- Decision Context Guard tests
- stale-context rejection
- simulation/live isolation
- end-to-end autonomous scenario smoke test
